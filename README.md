## 🚀 Запуск

```bash
# Просто открой в браузере:
open index.html

# Или через любой http-сервер:
npx serve .

# Или на Python:
python3 -m http.server 8080
```

Открой `http://localhost:8080` и готово!

## 🎯 Как играть

1. Выбери игру в главном меню
2. Установи ставку (кнопки `−` / `+` или `MAX`)
3. Нажми **КРУТИТЬ / СТАРТ / БРОСОК**
4. Выигрывай и забирай кэш!

> 💡 **Совет:** в Mines, Tower и Crash можно забрать выигрыш досрочно кнопкой **ЗАБРАТЬ**
